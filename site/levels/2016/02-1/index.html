Press the button that survives each move.

A constrained walk across the ordinary three-by-three bathroom keypad, one instruction line per code digit.

The idea: keep a coordinate for the current button, reject candidates outside the keypad, and record one button after each line. My real input produced 97289, accepted by Advent of Code.

Why Python

I chose Python because a coordinate dictionary makes legal buttons explicit and keeps the movement loop readable.

First idea

Each direction proposes a neighboring coordinate. I commit it only if the keypad contains that coordinate, then save the button at the end of the line.

Wrong turns

There were no wrong turns. Empty lines are ignored and every non-empty line is validated before it moves.

Constrained state walk

The current button is state, directions are transitions, and the keypad defines which transitions exist.
