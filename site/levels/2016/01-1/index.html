Why Python

I chose Python because a tuple of heading vectors makes the state transition direct and readable. The language stays out of the way of the city-grid idea.

First idea

I represent North, East, South, and West as a cyclic tuple. Every turn moves the index, then one vector-times-distance update moves the position.

Wrong turns

There were no wrong turns. Strict token parsing keeps malformed local input from silently changing the route.

State transition fold

Each instruction consumes one position and heading and emits the next state. The final state is all Part 1 needs.
