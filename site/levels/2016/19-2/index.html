Now each elf takes from directly across the circle. The survivor follows a power-of-three pattern, with a new piecewise branch after twice that power.

Enter an elf count and run the formula.
Let p be the largest power of 3 ≤ n.
n=p → n; n≤2p → n−p; otherwise → 2n−3p.

Concept

At every power of three the circle's elimination geometry resets. The result moves linearly within each branch, so the large input needs no list.
