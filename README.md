# Journey of Advent of Code

One puzzle level at a time, this repository records how I learn by solving Advent of Code in order. Each level keeps the working solution, the reasoning behind it, and an interactive explanation on the living site.

## How the journey works

I start with 2015 Day 1 Part 1 and unlock exactly one level at a time. A level moves from **locked** to **staged** while its public examples are understood and tested, then to **solved** only after the solution runs on my real puzzle input.

## Rules

- Link to the original [Advent of Code](https://adventofcode.com/) puzzle; never reproduce its text.
- Never commit puzzle inputs. Local inputs live under `inputs/` and are ignored by Git.
- Keep the wrong turns as honestly as the successful idea. If there were none, say so.
- Choose the language that makes the level clearest, not one language for the whole journey.
